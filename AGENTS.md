# Agent entry point

Read [program/rules.md](program/rules.md) and fill in or read
[program/experiment.md](program/experiment.md) before conducting experiments.

- `src/`: shared context and stable helpers.
- `evaluate/`: fixed tests, datasets, and evaluation settings.
- `experiments/`: baseline and one folder per trial.
- `logs/`: ideas, results, summaries, and evaluation output.

Follow the brief's selected mode and editable scope. Ask about missing required
setup details before running trials. No Git workflow is required.
